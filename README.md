# HABESHA Roleplay - Animated TikTok Stream Overlay 🚀

A high-performance, 100% transparent animated stream overlay suite built specifically for **TikTok LIVE Studio** and **OBS Studio** gaming streamers.

---

## 🌟 What's Included

### 🔗 3 Distinct TikTok Stream Layouts
1. **Pure Shining Logo (`logo.html`)**: The clean 3D chrome logo floating with 100% transparency. Perfect for placing right under your game capture screen!
2. **Middle Transition Divider (`divider.html`)**: The logo flanked by animated horizontal cyan laser rails spanning the 9:16 screen seam between your camera and gameplay.
3. **Cyber Gaming HUD (`hud.html`)**: Framed logo with glowing corner brackets, dark glass plate, and live status badge.

### ✨ 5 Animation Styles
- 💎 **Diamond Chrome Gleam**: Smooth specular sheen reflection sweep with timed 5-point starburst glints.
- ⚡ **Electric Pulse**: Powerful rhythmic neon cyan aura heartbeat surge.
- 🌊 **Liquid Chrome**: Continuous undulating metallic ripple caustics.
- 👾 **Cyber Glitch**: Futuristic holographic RGB-split flicker and strobe flare.
- 🌌 **Zenith Minimal**: Slow-motion executive glass glide with subtle ambient backlight.

## 🚀 How to Host Online (Netlify or GitHub)

### Method 1: Netlify Drop (Easiest - 10 Seconds, No Code)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this entire project folder (`habesha-stream-overlay`) onto the page.
3. Netlify will immediately generate your permanent free HTTPS link (e.g., `https://habesha-stream.netlify.app`).
4. Paste that link directly into TikTok LIVE Studio!

### Method 2: GitHub Pages
1. Push this folder to a new GitHub repository (e.g. `https://github.com/Nezafilm/habesha-stream`).
2. Go to **Settings** &rarr; **Pages** &rarr; Select `main` branch &rarr; click **Save**.
3. Your live link will be `https://nezafilm.github.io/habesha-stream/`!

---

## 🎮 How to Add to TikTok LIVE Studio
1. Click **Add source** on the left panel.
2. Select **Link**.
3. Paste any of the 3 links (e.g., `https://your-site.netlify.app/logo.html`).
4. Set Resolution to **1080 x 500** (or your stream width).
5. Drag and position it directly below your FiveM game screen!
